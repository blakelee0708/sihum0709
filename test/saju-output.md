# 만세력 계산 검증 결과

PRD 17장이 지정한 검증 사례 10건의 계산 결과입니다.

다른 만세력 서비스에 같은 생년월일시를 넣어 아래 표와 대조해 주십시오.
대조가 끝나면 `lib/saju/calculate.test.ts` 의 `EXPECTED` 표에 정답을
채워 넣으시면 테스트가 실제 검증으로 바뀝니다.

> 이 파일은 `npm test` 실행 시 자동으로 다시 생성됩니다. 직접 고치지 마십시오.

## 이 서비스의 계산 기준

다른 만세력과 값이 다르면 대개 아래 세 가지 중 하나 때문입니다.

| 항목 | 이 서비스의 처리 | PRD 근거 |
|---|---|---|
| 경도 보정 | 출생 시각에서 **30분**을 뺍니다 | 4.2 0단계 |
| 서머타임 | 시행 기간이면 **추가 60분**을 뺍니다 | 4.2 0단계 |
| 자시 | 23:00-23:59는 **당일 유지**(조자시) | 4.3.1 |
| 입춘 경계 | **보정 후 시각**으로 비교합니다 | 4.2 (0단계 → 1단계 순서) |
| 절기 시각 | skyfield + DE421로 계산한 KST 분 단위 | 4.1.1 |

### 확인이 필요한 지점

PRD 4.1.1의 예시 JSON은 2026년 입춘을 `2026-02-04 05:46`으로 적고 있으나,
skyfield로 계산한 실제 값은 `2026-02-04 05:02` 입니다.

생성한 테이블은 2024년 입춘 17:27, 2025년 입춘 2월 3일 23:10 등
공표된 만세력 값과 일치하므로 계산 쪽이 맞다고 보고 진행했습니다.
PRD 예시는 형식 설명용 숫자로 판단했습니다.

이 때문에 PRD가 지정한 "입춘 당일 05:45 / 05:47" 사례(2, 3번)는
둘 다 같은 년주가 나옵니다. 실제 경계를 확인하실 수 있도록
보정 후 입춘을 사이에 두는 4, 5번 사례를 따로 넣었습니다.

- 보정 후 2026-02-03 11:30
- 명식 을사 기축 무신 무오
