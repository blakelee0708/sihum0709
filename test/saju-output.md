# 만세력 계산 검증 결과

확정된 계산 규칙이 의도대로 동작하는지 확인한 결과입니다.

> 이 파일은 `npm test` 실행 시 자동으로 다시 생성됩니다. 직접 고치지 마십시오.

## 확정된 계산 규칙

| 항목 | 처리 | 적용 대상 |
|---|---|---|
| 경도 보정 | 30분을 뺍니다 | **시주만** |
| 서머타임 보정 | 시행 기간이면 60분을 더 뺍니다 | **시주만** |
| 절기 경계 | 보정하지 않은 **원본 시각**으로 비교 | 년주, 월주 |
| 일주 | **원본 날짜** 기준 경과일 | 일주 |
| 자시 | 23:00-23:59는 당일 유지 (조자시) | 일주 |
| 오행 강약 | 일간 3, 월지 3, 나머지 각 1. 지장간 미반영 | 오행 분포 |

절기 테이블이 KST 기준이라 보정된 시각을 맞대면 기준이 섞입니다.
그래서 절기 경계는 원본 시각으로 봅니다.

반면 시지는 실제 태어난 시각을 묻는 자리이므로 보정을 적용합니다.
그 결과 실질 자시 시작이 23:30으로 밀립니다. 의도한 동작입니다.

참고로 2026년 입춘은 `2026-02-04 05:02` 입니다.
2024 / 2025 / 2026년 절입 36개가 공표 절기표와 분 단위까지 일치합니다.
